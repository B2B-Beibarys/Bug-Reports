# Test Cases - Janymda App (Beeline) / Супер-игра

## TC-001 - Случайность порядка вопросов в супер-игре

| Поле | Описание |
|---|---|
| **Предусловие** | Пользователь авторизован, открыта игра "Music and Movies" с призом в 1+ ГБ |
| **Шаги** | 1. Запустить раунд и дойти до супер игры и запомнить ответ супер-игры. 2. Завершить раунд 3. Запустить новый раунд |
| **Ожидаемый результат** | Вопросы Супер-Игры появляются в случайном порядке |
| **Фактический результат** | Вопросы Супер-Игры повторяются в той же последовательности |
| **Severity** | Critical |
| **Статус** | FAIL |

## TC-002 - Многократное получение приза через знание порядка

| Поле | Описание |
|---|---|
| **Предусловие** | Пользователь прошёл хотя бы один раунд и запомнил ответ на вопрос Супер-Игры |
| **Шаги** | 1. Запустить новый раунд. 2. Дойти до Супер-Игры и ответить на основе запомненного вопроса
3. Завершить раунд и получить приз 4. Повторить шаги 1–3 несколько раз|
| **Ожидаемый результат** | Повторное прохождение не даёт гарантированной победы |
| **Фактический результат** | Пользователь получает 1 ГБ в каждом раунде с вероятностью 100% |
| **Severity** | Critical |
| **Статус** | FAIL |
